# 2026.290.1513 — fix(cuda): advance the layer-nvidia pin past the Arch gpgcheck fix (#12)

## Summary

Advances this repo's `layer-nvidia` pin off `v2026.271.1817` and onto the **merge commit of
`opencharly/layer-nvidia#12`** (`054aa7702ebe79e8be444764f91a03933ba45eec`) — the change that moved the
`nvidia-container-toolkit` gpgcheck assertion *into the command* so the Arch arm can skip honestly instead of
failing. One line in the root `charly.yml`; no other pin moves.

The stale pin is real and was re-measured against the API rather than recalled: `main` pinned `v2026.271.1817`
while the fix merged around CalVer day 289. It is visible from the consumer side — `opencharly/layer-strata`'s
`check-strata-gpu-pod` builds a tree whose transitive `layer-nvidia` is that old pin, so the bed runs the
**pre-#12** probe and fails on `nvidia-container-toolkit-gpgcheck-enforced`.

A merged SHA is used rather than the tag, deliberately: it is an immutable ref, and `charly box reconcile`
already reports this tree as aligned ("every repo's pins are at one version").
