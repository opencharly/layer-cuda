# 2026.329.1939 — feat(cuda)!: install the toolkit driver-free and delete the driver strip

## Summary

The toolkit installs **driver-free at the source**, and the strip step is gone.

`pacman -S cuda` pulls `opencl-nvidia` (three host-coupled driver files); `cudnn` depends on `cuda`.
The pac arm no longer declares them. The **FIRST plan step** installs both with that dependency
treated as satisfied:

```
pacman -Syu --noconfirm --needed --assume-installed opencl-nvidia cuda cudnn
```

so the driver never enters the image at the SOURCE — the pod receives it from the host through CDI,
its only provider. `cuda-drop-driver-userspace` (with its comment block) is deleted with the mechanism
it served; a new **absence assertion** replaces its residue check and FAILS if any driver surface is
baked; the `cuda` skill teaches the new contract instead of the strip.

The **Fedora arm is retired** with this cutover: it has no consumer after the Fedora CDI boxes were
dropped (opencharly/distro-fedora#137), and the strip it relied on ran on every distro. The layer is
**Arch/CachyOS-only**, and the absence assertion covers the **libraries, the `nvidia*` binaries and
the `nvidia`/`vdpau`/xorg trees** the old strip handled — a baked driver surface of any kind reds
the build.
