# 2026.289.1250 — fix(cuda): the CCCL headers are `cccl-devel`, not `cuda-cccl-devel`

## Summary

The `cuda` candy's RPM package list pinned `cuda-cccl-devel`, which no enabled repo provides, so every GPU image failed its dnf transaction. This replaces it with `cccl-devel` — the name the CCCL headers actually ship under — and corrects the `cuda-skill` description prose that repeated the old name. Both sites move together, as the issue requires.

- `charly.yml` RPM package list: `cuda-cccl-devel` → `cccl-devel`, carrying a comment that records the repo split making the name load-bearing (`fedora-multimedia` provides `cccl-devel`; `cuda-nvcc`/`cuda-cudart-devel` carry no `cuda/std` files, so the line cannot simply be dropped).
- `charly.yml` `cuda-skill` description: the RPM list in the prose follows the code.

Closes #7.
